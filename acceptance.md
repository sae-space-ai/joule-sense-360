# Acceptance gates
- [ ] OpenCV runtime asserts major version 5.
- [ ] At least two distinct visual observations influence a changed agent action, recorded by trace.
- [ ] Compare baseline without memory, static memory, and active memory across a documented dataset.
- [ ] Document success AND failure examples, uncertainty, false positives, latency and cost.
- [ ] AWS service runs an actual meaningful workload with reproducible configuration and CloudWatch/log evidence.
- [ ] Pin dependencies and demonstrate fresh install/build/test.
- [ ] Judge-accessible demo/endpoint, repository, architecture diagram and video <=5 min.
- [ ] If claiming COOL: report version, ARM workload, comparable baseline, measurements and commands.
- [ ] Privacy review, no unconsented media; no independent navigation trial.
