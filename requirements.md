# Competition mapping — source: user-supplied OpenCV AI Competition 2026 brief
## Required
- Substantial OpenCV 5 image/video analysis.
- Significant component executing on AWS.
- Technical report: problem, users, architecture, OpenCV, AWS, evaluation, limitations, responsible use.
- Judge-accessible code repository/archive; pinned dependencies; build/deploy/test instructions.
- Architecture diagram showing OpenCV and AWS.
- Functional web endpoint or arranged live screen-share.
- Public/unlisted judge-accessible video up to 5 minutes: team, working app, architecture, main findings.
- Appropriate evaluation including failures.

## Agentic Vision special prize
- Perception → decision/plan → action loop with OpenCV output influencing subsequent tool call/action/human approval.
- Agent workflow diagram, evidence trace of changed actions, success and failure evaluation, observability, suitable human control.
- Merely describing a static image with a chatbot does NOT qualify.

## COOL special prize (optional)
- COOL must run primary stated vision workload on AWS Graviton/ARM or documented hybrid ARM route.
- Provide precise COOL version, deployment details, reproducible baseline, inputs and measurements.
- Claim eligibility only after actual measured execution.

## General evaluation weights
Technical execution 30%; innovation 20%; real-world impact 20%; UX 10%; documentation/presentation 10%; AWS/reproducibility/responsible operation 10%.
